# TISHA RESTRO — The Art of Indian Dining

A luxury haute Indian gastronomy web experience built with React, Three.js WebGL, and Tailwind/Vanilla CSS.

## 🏛️ Highlights & Features

- **Cinematic Hero Video & 3D WebGL Scene**: Fullscreen cinematic restaurant video background and Three.js 3D floating spices in celestial orbit.
- **10-Scene Cinematic Story Progression**: Interactive horizontal chapter scrubber (`01` through `10`) with live hero timeline synchronization.
- **Interactive Table Map & Imperial Booking**: 4 architectural dining zones, visual floor plan, live table availability status, and WhatsApp confirmation dispatch.
- **Tisha AI Concierge**: Digital Maître d' with speech-to-text dictation, voice audio narration, dining mood personas, compact culinary cards, and direct WhatsApp VIP handoff.
- **Interactive Menu Repertoire**: Chef specials, dietary filters, spice level meter, and interactive add-to-order drawer.
- **Architectural Sanctuaries & Moments in Motion**: Photography stills, Pinterest luxury ambiance backdrops, and walkthrough video lounge.
- **Fully Responsive & Production Ready**: Optimized for desktop, tablet, and mobile with zero text overlap and high-contrast typography.

## 🚀 Tech Stack

- **React 19**
- **Vite 8**
- **Three.js** (WebGL 3D Interactive Graphics)
- **Lucide React** (Vector Icons)

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 🌐 Deploy to Vercel

1. Push code to GitHub repository: `https://github.com/Animeshboom/democaferesturent.git`
2. Import repository into [Vercel Dashboard](https://vercel.com).
3. Framework preset: `Vite`.
4. Click **Deploy**.
